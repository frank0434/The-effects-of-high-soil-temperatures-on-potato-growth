# The-effects-of-high-soil-temperatures-on-potato-growth

The repository for manuscript _The effects of high soil temperatures on potato growth_


# Technical details:

## Folder layout

The [data folder](/data/) has the experimental data for this research.   
The [scripts folder](/scripts/) contains all the essential code for analysis and visualisation.   
The [figures](/figures/) and [results](/results/) folders are for the output from R scripts. 

## R packages

The [00_setup.R](/scripts/00_setup.R) load the shared R packages for all R scripts. This script also provides metadata for the crop season and treatment duration, along with other constants for visualisation etc. One thing may need attention is the [data.table](https://cran.r-project.org/web/packages/data.table/vignettes/datatable-intro.html) package used in this work. The code syntax is slightly different from common tidyverse style.
