# The Effects of High Soil Temperatures on Potato Growth

Repository accompanying the manuscript:

> *The Effects of High Soil Temperatures on Potato Growth*

## Repository structure

The repository is organised as follows:

- `/data` contains the experimental data used in this study.
- `/scripts` contains all code required for data processing, statistical analyses, and visualisation.
- `/figures` contains figures generated by the analysis scripts.
- `/results` contains output files generated from the analyses.

## Reproducibility

All analyses and visualisations can be reproduced using the scripts provided in the `/scripts` directory.

### R packages

The script `scripts/00_setup.R` loads the shared R packages used throughout the project. It also provides metadata describing the crop season, treatment durations, and other constants used for analysis and visualisation.

This project makes extensive use of the `data.table` package for efficient data processing. Users unfamiliar with `data.table` should note that its syntax differs from the more commonly used tidyverse approach.

For an introduction to `data.table`, see:

https://cran.r-project.org/web/packages/data.table/vignettes/datatable-intro.html
